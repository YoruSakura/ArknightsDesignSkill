# Endfield UI（明日方舟：终末地）基础设计规范

> 来源依据：`icaruszezen/endfield-ui`（MIT 协议）· 《明日方舟：终末地》官网、云游戏页实测数据与游戏界面规范。

---

## 一、 一句话定位与三种载体

**一句话定位**：**工业编辑风（Industrial Editorial）**——把界面当成一份印出来的技术文档与工业画册：**纸白（`#FFFFFF`）或烟黑（`#141414`）的底、墨黑的字（`#191919`）、一处高饱和的信号黄（`#FFFA00`）**，再叠上一层克制的测绘与印刷痕迹。

> [!IMPORTANT]
> **终末地风格 ≠ "黑底黄字加切角"！** 官网绝大部分版块是**白纸墨字**的；切角是游戏内行动与机械控件的语言，官网几乎不用切角。做设计前必须先确认自己在做哪一种载体：

| 维度 | 载体 1：官网画册（默认） | 载体 2：游戏实机界面（Game UI） | 载体 3：宣传物料 / 版本专题 |
| :--- | :--- | :--- | :--- |
| **基底** | 纸白 `#FFFFFF` 为主，穿插深色版块（世界观/影像） | 亮暗并存，按界面家族（A–G）选择 | 随当期版本/角色主题变化 |
| **强调色** | 信号黄 `#FFFA00` 唯一一种 | 信号黄 + 分工明确的角色色（橙/黄绿/蓝/青/红/绿/紫） | 当期版本/地区主题色可整页接管（`--ef-action`） |
| **形状** | 直角为主，按钮 4px 微圆角，圆与胶囊点缀 | 直角、45° 切角、斜楔、正圆、胶囊按语义混用 | 自由，刊头与色带标题张扬 |
| **信息密度** | 低，大片留白、大图大字、偏心构图 | 高，中心留空或矩阵工作区，信息靠边停靠 | 中到高，按章节/时间轴排布 |
| **装饰母题** | 斜纹（`hatch`）、点阵（`dot-grid`）、注册色条（CMY）、镂空巨字 | 工程网格（`blueprint-grid`）、等高线（`contour`）、角括号、刻度环 | 加上印章、批注、贴纸等「人的痕迹」 |

## 二、 六条核心原则（判断"像不像"的唯一标准）

### 1. 纸与墨是主体，颜色是信号
* 大面积永远只用 13 级纯中性灰阶（`R = G = B`，无冷暖色偏）。
* **信号黄 `#FFFA00` 只出现在需要被看见的那一处**：当前导航项、唯一的主要行动按钮、进度条填充、选中环。**一屏里黄色面积超过 10%，多半是用错了。**
* **铁律：黄色只做底，绝不做亮底上的字！** `#FFFA00` 在白底上对比度仅 `1.11:1`（完全看不见）。
  * 黄底填充上必须压墨字 `--ef-on-action` (`#191919`，对比度 `15.9:1`)；
  * 亮色表面上需要强调色文字或细线时，必须用深档 `--ef-accent-ink`（亮色下自动为 `#6B5D00`，暗色下自动为 `#FFFA00`）。

### 2. 主角偏心，信息靠边
* **偏心构图**：人物立绘、主视觉图、核心大字或地图占据偏离画面中心的大块面积；导航（左侧窄轨 `SideRail`）、标签、说明、次要入口各贴一条边停靠。
* **不等宽分栏**：栅格优先用不等宽比例，如 `grid-template-columns: minmax(0, 1.6fr) minmax(16rem, 0.8fr)`，**严禁把整个页面做成居中对称的"页眉 + 三张等大卡片 + 页脚"通用后台模板**。
* **分三个平面**：
  1. **背景层**：镂空巨字（`//SECTION`）、工程网格、等高线、点阵（极低对比度，允许越界被容器截断，`pointer-events: none`）；
  2. **内容层**：主图、正文、数据表；
  3. **前景层**：侧轨导航、主要行动、浮层（面积小、对比最高、带零偏移环境阴影）。

### 3. 形状有含义，默认不围整圈边框
* **四类形状各司其职**（同一语义全站保持同一种形状）：
  * **直角（`0px`）**：面板、卡片、输入框、表格、弹窗、静态归档标签（`TagPair`）；
  * **微圆角（`4px`）**：按钮一族（`Button`、方形图标钮、主行动块 `NavAction`）统一 `4px`；
  * **45° 切角与斜楔（`cut-tr` / `wedge-r`）**：仅用于**主要行动、机械部件、权限/等级标识、楔形一级页签**（一个元素只切一个角或一组对角，**严禁四角全切八边形**，**严禁给普通文章卡片或输入框切角**）；
  * **正圆与圆弧（`rounded-full`）**：代表「人、技能、仪表、翻页」（圆形头像 `Avatar`、白色圆形翻页钮、进度环 `ProgressRing`、刻度圆环 `TickRing`）；
  * **胶囊（`rounded-full`）**：代表「可变状态、筛选、资源、短状态」（筛选胶囊 `FilterChip`、顶部资源条 `ResourceChip`、胶囊导航器 `Navigator`、倒计时 `Countdown`、开关 `Switch`）。
* **默认不围整圈边框**：层次靠**底色差、一条底边线或一条左缘短竖条**交代。例如：
  * 统计块（`Stat`）**不装进卡片框**，只用左侧一条 `3px` 墨色竖线；
  * 页面内提示条（`Alert`）**不围外框**，只用 `surface-raised` 底 + 左缘 `4px` 语义色条；
  * 输入框默认是 `sunken`（凹陷底 `#F2F2F2` + 底部 `2px` 线），不画四边圆角框。
* **零偏移环境阴影**：所有阴影均为 `0 0 <blur> rgba(0,0,0,α)`（无 X/Y 偏移），仅用于浮层、侧轨和按钮，**不用阴影做卡片层次，悬停时绝不上浮、绝不放大阴影**。

### 4. 两种文字，两个层次（微文字必须说真话）
* **中文黑体负责阅读**（`--font-sans`: HarmonyOS Sans SC / Noto Sans SC）；**英文负责结构**（分节名、编号、坐标、微标签）。
* **英文分三种字体脾气**：
  1. `--font-display`（宽体大写 `Archivo` wdth 125 / `Montserrat`）：镂空巨字、色带大标题、分页页码 `01 / 04`；
  2. `--font-latin`（几何无衬线 `Outfit` / `Urbanist`）：分节标题英文（`GAMEPLAY`）、代号；
  3. `--font-tech`（技术等宽数字 `Space Grotesk`）：一切变化的数字、微标行 `// NOTICE 2026.10.07`、坐标读数。
* **字阶跨度大、中间档少**：正文 `16px` 到分节标题直接翻倍（`32px`），再到页面标题 `52px`、代号 `72px`、镂空巨字 `clamp(5rem, 10.4vw, 12.5rem)`。
* **铁律：微文字必须是真话！** 小号英文是技术副层，必须写真实的栏目名（`// OVERVIEW`）、真实版本号（`REV 2026.11`）、真实章节进度（`SECTION 02 OF 04`）。**严禁编造伪十六进制乱码（`0x7F3A::SYS`）、假经纬度或无意义的科幻词（`QUANTUM LINK OK`）！**

### 5. 纹理有预算
* 斜纹（`hatch`）、点阵（`dot-grid`）、工程网格（`blueprint-grid`）、等高线（`contour`）、注册色条（CMY `ef-reg-strip`）、警示条纹（`hazard`）都是可选的。
* **预算控制**：操作界面 0～1 种，内容页 1 种，落地页一屏 1～2 种。去掉所有纹理后界面结构依然成立，才说明纹理没有喧宾夺主。
* **严禁通用科幻俗套**：不要霓虹辉光、不要全屏噪点、不要玻璃拟态卡片、**不要六边形蜂窝网格**。

### 6. 动得短，动得硬
* 日常交互过渡控制在 `200ms`（换色/透明度）与 `300ms`（位移/展开/擦入），使用标准 `ease` / `ease-out`，**严禁弹簧过冲回弹（bounce/spring）**。
* **悬停只换色，不上浮、不放大**。
* **标志性入场动效**：
  * `animate-flicker`：模拟设备通电的三次短促闪烁点亮（`10%`、`20%`、`40%` 闪烁后常亮，600ms），仅用于主图或标题块入场一次；
  * 分节标题三步揭示：灰色滑块从左滑入（`animate-slide-in`）$\rightarrow$ 块内斜箭头 `↘` 从 `-45°` 转正（`animate-turn-in`）$\rightarrow$ 文字淡入（`animate-fade-in`）；
  * 输入框聚焦：底部 `2px` 墨线从左往右擦出（`clip-path: inset(0 100% 0 0)` $\rightarrow$ `inset(0)`，300ms）。

## 三、 色彩与角色色令牌表（`--ef-*`）

直接引入 [`resources/endfield-standalone.css`](../../resources/endfield-standalone.css)（通用纯 CSS）或 [`resources/endfield-theme.css`](../../resources/endfield-theme.css)（Tailwind v4）即可使用。

### 1. 语义表面与文字令牌（支持 `data-theme="light | dark | inverse"`）

| 语义令牌 | 亮色（Light 默认，官网） | 暗色（Dark，HUD/深色版块） | 用途 |
| :--- | :--- | :--- | :--- |
| `--ef-surface` | `#ffffff` | `#141414` | 页面主画布背景 |
| `--ef-surface-raised` | `#fafafa` | `#1f1f1f` | 面板、卡片、弹窗、提示条表面 |
| `--ef-surface-sunken` | `#f2f2f2` | `#000000` | 凹陷区域、输入框底、数据行带画布 |
| `--ef-surface-muted` | `#e6e6e6` | `#282828` | 悬停底、激活页签底、分页条底 |
| `--ef-surface-inverse` | `#191919` | `#fafafa` | 反转块底（面板标题带、表头带、`TagPair` 名块、主行动块） |
| `--ef-ink` | `#191919` | `#fafafa` | 主文字、主线条、选中粗条 |
| `--ef-ink-secondary` | `#626262` | `#b3b3b3` | 次级文字、微标行 |
| `--ef-ink-tertiary` | `#8a8a8a` | `#8a8a8a` | 大字号装饰文字、方括号 `[ ]`、占位符 |
| `--ef-ink-inverse` | `#ffffff` | `#191919` | 反转块上的文字 |
| `--ef-line` | `#d9d9d9` | `#383838` | 1px 发丝分隔线、面板外框 |
| `--ef-line-strong` | `#b3b3b3` | `#626262` | 输入框 2px 底边线、筛选胶囊细边 |
| `--ef-action` | `#fffa00` | `#fffa00` | 信号黄填充（若做纯游戏内界面可覆盖为 `#fcea00`） |
| `--ef-on-action` | `#191919` | `#191919` | 信号黄底上的墨色文字 |
| `--ef-accent-ink` | `#6b5d00` | `#fffa00` | **强调色文字/细线**（亮底自动取深橄榄金，暗底自动取信号黄） |
| `--ef-accent-ink-inverse` | `#fffa00` | `#6b5d00` | **反转块（`surface-inverse`）上的强调记号**（如面板黑标题带左端的黄竖条） |
| `--ef-button` / `-hover` | `#383838` / `#484848` | `rgb(255 255 255 / 0.2)` / `0.3` | 默认 `control` 按钮底色（暗色下自动变为半透明白） |

> **项目品牌换色接口**：保持 13 级中性灰纸墨基底不变（或仅微调倾向），直接覆盖 `--ef-action` / `--ef-action-pressed` / `--ef-on-action` / `--ef-accent-ink` / `--ef-accent-ink-inverse`（`.ef-band-title`、`.ef-hazard`、`.ef-data-row__val--accent` 等均已联动 `--ef-action`）。换成深色品牌主色时须将 `--ef-on-action` 改为 `#ffffff`，亮底文字强调 `--ef-accent-ink` 须取深档高对比色，强调面积仍控制在 $\le 10\%$。

### 2. 游戏界面角色色（Role Colors）与语义分工

> [!WARNING]
> **进度归黄，量值归蓝；注意归橙，危险归红！** 严禁混用：

| 令牌 | 色值 | 唯一职责 | 严禁用于 |
| :--- | :--- | :--- | :--- |
| `--color-signal` (`--ef-action`) | `#FFFA00` | 主要行动、选中态、**进度条填充（灰轨+黄条）** | 亮底上的文字、大面积背景卡片描边 |
| `--color-notice` | `#FC6C00`（橙） | 通知角标、倒计时提醒、数量/折扣 | 表示报错或危险 |
| `--color-gain` | `#BCE41D`（荧光黄绿） | 增益标签（`+6%`）、经验增量（压 `#191919` 墨字） | 填充进度条 |
| `--color-data` | `#2A84B4`（蓝） | **数量/产出图表（Sparkline 面积图）**、流程连线 | 表示"完成了百分之多少"的进度条 |
| `--color-region` | `#06A2A2`（青） | 地区/机构专属主题色 | 通用数据色 |
| `--color-alert` / `--ef-danger` | `#F62A2A` / `#DE0909` | 危险、超支、不可逆删除 | 普通未读装饰、常规高亮 |
| `--color-confirm` / `--ef-success` | `#00D872` / `#007F43` | 确认、充裕倒计时、完成状态 | — |
| `--color-rarity-1..4` | `#24BAFC` (蓝) $\rightarrow$ `#904EF6` (紫) $\rightarrow$ `#FCBA00` (金) $\rightarrow$ `#FC6C00` (橙) | 物品格（`ItemSlot`）**底部 40% 向上消散的渐变** | 整圈彩色描边 |

## 四、 游戏界面七大家族（做功能应用/后台时先选家族）

当用户需要构建一个功能型界面（而非宣传官网）时，先从以下七大家族中选定宏观骨架：

1. **A. 运行界面与系统枢纽（HUD / Hub）**：中心留空给场景或中央圆形区域；状态、技能（圆环）、资源（顶部胶囊）、行动（右下黄色切角/斜楔块）停靠四角。
2. **B. 地图与区域（Map & Region）**：全幅等高线（`contour`）画布 + 左上 `// 模块 / 子页` 面包屑 + 边缘区域导航 + 选中区域的悬浮详情面板；支持地区主题色整页接管（覆盖 `--ef-action`）。
3. **C. 角色与装备（Character & Equipment）**：偏心大立绘/模型 + 浅灰摄影棚网格底 + `[ 角色名 ]` 方括号标题 + 名值对（`TagPair`）属性 + 侧边圆形头像切换器。
4. **D. 仓库、商城与矩阵（Depot & Matrix）**：密集直角物品格（`ItemGrid` + `ItemSlot`，底部稀有度渐变 + 选中时四角 `corner-brackets` 落位）+ 顶部横向筛选胶囊（`FilterChip`）與资源胶囊（`ResourceChip`）+ 右侧固定详情面板。
5. **E. 技能树与流程（Tech Tree & Pipeline）**：浅纸底 + 工程网格（`blueprint-grid`）+ 直角折线连接节点 + 幽灵大数字标示阶段。
6. **F. 数据简报与监控（Data Briefing & Monitor）**：浅色凹陷画布（`surface-sunken`）上排列一条条**固定深色（`#141414`）的数据行带（`DataRow`）**，行左 4px 类目色条 + 收藏圆点，行中内嵌无坐标轴小型面积图（`Sparkline`），行右等宽数值（蓝=产出，黄=消耗，红=超支）。
7. **G. 通讯与信息工具（Comms & Encyclopedia）**：清晰阅读列 + 索引列表；完成态使用明暗反转横幅（`CompletionBanner`：深底 + 黄字 + 巨型描边词 `COMPLETED`）。
